# 一页账 · 演示版

这是个人记账网页的公开演示版。所有日期、金额与交易均为**虚构示例**，不包含真实账目。打开 `index.html` 即可体验月度、季度、年度账单、日历、分类和交易筛选。

## 本地预览

直接在浏览器中打开 `index.html`。页面只依赖本目录中的 `data.js`、`core.js`、`app.js` 和 `style.css`。

GitHub Pages 从 `main` 分支的 `/ (root)` 目录发布，入口文件是 `index.html`。

如需更新演示数据，只编辑这里的 `data.js`。请勿将真实账目、银行卡信息或原始收据上传到这个公开仓库。
